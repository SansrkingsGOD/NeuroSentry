# Sample Data Documentation

## Purpose
This folder contains sample data to demonstrate the proposed EEG data structure for NeuroSentry.

## File Description
- `sample_eeg.csv`: A synthetic example containing four illustrative EEG channel values and a placeholder label.

## Column Details
- `sample_id`: Unique sample identifier.
- `channel_1` to `channel_4`: Illustrative channel values.
- `label`: Placeholder label for demonstration purposes.

## Limitations
- These values are synthetic and are not real EEG recordings.
- They have not been collected from human participants.
- They are not suitable for training or evaluating a real EEG classification model.
- Actual signal units, sampling rate, and electrode configuration will be documented after the acquisition hardware is finalized.

## Privacy and Safety
No personal or patient information is included in this sample file. Any future real EEG data must be handled with appropriate consent and privacy safeguards.
